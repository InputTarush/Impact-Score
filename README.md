🏓 IMPACT SOURCE
An end-to-end AI-powered talent identification and sponsorship ecosystem. The platform leverages Computer Vision (OpenCV) and Local LLM Intelligence (Ollama / Qwen 2.5) to automatically analyze athlete gameplay videos, calculate deep biomechanical joint metrics, generate technical coaching reports, and connect verified players with Corporate Social Responsibility (CSR) grant funding.

🌟 Executive Summary
Traditional sports talent discovery relies heavily on manual, localized scouting—making it difficult for promising athletes in remote areas to access sports funding.

This platform bridges that gap by offering a two-sided digital ecosystem:

Player Portal: Athletes upload raw gameplay footage (local file or cloud URL) to run an automated AI mechanics evaluation. The system outputs real-time stroke scores, 2D kinematic telemetry (elbow angles, knee flexion), and an executive coaching assessment generated by an LLM.

CSR Agent Portal: Funding partners and grant evaluators access a discovery feed of verified athletes. Evaluators can filter candidates using multi-attribute sliders (age, impact score, stroke performance), inspect full frame-by-frame joint telemetry and video evidence, and allocate structured grant funding directly.

✨ Key Features
🏃 Player Portal & AI Evaluation Engine
Automated Motion Analysis: Evaluates player footage across key athletic dimensions: Forehand, Backhand, Footwork, Reaction, and Endurance.

Vision Engine Telemetry (OpenCV): Extracts frame-by-frame kinematic joint telemetry, including average elbow stroke angles (optimal: 115°–125°) and stance knee flex angles (optimal: 130°–142°).

LLM Technical Coaching Report: Interfaces with a local Ollama instance (Qwen 2.5 model) to generate individualized coaching advice based on computer vision stats.

Interactive Skill Radar: Visualizes athlete performance profiles using custom Plotly polar radar charts.

💼 CSR Agent Portal & Audit Dashboard
Verified Talent Discovery Feed: Displays candidate cards of athletes who have completed AI mechanics verification.

Multi-Attribute Interactive Filters: Dragger-style range sliders allow CSR agents to filter talent by Impact Rating (0–100), Age, Gender, and specific stroke score thresholds.

Deep Biomechanical Audit Modal: CSR evaluators can expand an athlete's profile to view complete Ollama coaching breakdowns, raw JSON telemetry outputs from the vision engine, and embedded gameplay video playback.
